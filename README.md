# GAMEVERSE - Tienda de videojuegos

Abre `index.html` en el navegador.

1. Crea tu cuenta (Registro) e inicia sesión.
2. Usa el menú izquierdo: Principal, Catálogo, Carrito, Lista de productos y Créditos.
3. Agrega juegos al carrito y pulsa "Pagar" para ver tu boleta.

Las cuentas se guardan en el navegador (localStorage), no hay servidor.
